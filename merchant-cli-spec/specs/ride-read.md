实现 ride 只读命令：填充 src/ride/quote.ts、src/ride/get.ts、src/ride/list-orders.ts（foundation 已建骨架与 builder 契约，保持其导出签名）。仅依赖 core/types/utils，命令文件之间不互相 import、不共享可变状态。quote.ts：POST /api/v2/rides/search；flags --pickup-lat/--pickup-lng/--pickup-name/--dropoff-lat/--dropoff-lng/--dropoff-name/--pickup-time(epoch 秒或 now)/--passenger-name/--passenger-phone(E.164)，可选 --passenger-count/--luggage-count/--passenger-email/--children-count；body 用 snake_case：pickup{lat,lng,name}、dropoff{lat,lng,name}、pickup_time、passenger_name、passenger_phone 等；响应展示 vehicle_classes[]（vehicle_class、price{amount,currency,quote_id}、passenger_capacity、luggage_capacity）、meet_and_greet、is_airport_transfer、airport_direction；金额是货币常规单位(42.50=$42.50，非分)，不要乘/除 100。get.ts：GET /api/v2/rides/{order_id}/status，flag --order-id（取值为 book 返回的 ride_id），展示 status/from/to/pickup_time/vehicle_class/price/passenger/driver(派单后)/vehicle(派单后)，可重复调用用于轮询，状态枚举大小写敏感，终态 At destination/Cancelled/Rejected/Customer no show/Driver no show。list-orders.ts：GET /api/v2/rides/orders，query page(默认1)/page_size(默认20)，可选 status/order_type，展示 orders[]/total/page/page_size。三者均只读，默认 --format json 输出后端 data，--format table 走 formatter 人类可读；支持 --help --format json 输出参数/响应 schema；错误以后端 error.code 透传。
