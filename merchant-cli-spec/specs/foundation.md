在仓库根新建独立 Node.js CLI 包 merchant-cli/，搭建脚手架、内置 core 底座，并在入口接线全部命令骨架。强约束：只新建 merchant-cli/ 下的文件，绝不修改仓库根已有的 src/、package.json、tsconfig.json、tsup.config.ts、vitest.config.ts 等（属于已发布的 agenzo-token-cli，原样不动）。技术栈对齐 token-cli：TypeScript + ESM + commander@^14 + @inquirer/prompts@^8 + tsup@^8，Node 18+。创建文件：1) package.json：name=agenzo-merchant-cli，type=module，main=dist/index.js，bin {agenzo-merchant-cli: dist/index.js}，scripts {build: tsup, dev: tsup --watch, lint: eslint src, prepublishOnly: npm run build}，dependencies {commander ^14, @inquirer/prompts ^8}，devDependencies {typescript ^6, tsup ^8, @types/node ^25, eslint ^9, @eslint/js ^9, typescript-eslint ^8}，engines node>=18，files [dist, README.md, SKILL.md]。2) tsconfig.json：target/module/lib ES2022，moduleResolution bundler，types [node]，strict，esModuleInterop，skipLibCheck，resolveJsonModule，declaration，outDir dist，rootDir src，include src/**/*。3) tsup.config.ts：entry src/index.ts，format [esm]，target node18，outDir dist，clean，dts，sourcemap，banner.js 设为 #!/usr/bin/env node。4) eslint.config.js：扁平配置，基于 @eslint/js recommended + typescript-eslint recommended（非类型感知，确保可单文件 lint），仅 lint src 下 .ts。5) src/core/errors.ts：SCREAMING_SNAKE_CASE 错误码常量 + CliError 类（code/message/可选 recovery/退出码）。至少含 QUOTE_EXPIRED, VEHICLE_UNAVAILABLE, BOOKING_FAILED, CANCELLATION_NOT_ALLOWED, SERVICE_NOT_FOUND, PARAM_IDEMPOTENCY_KEY_REQUIRED, NETWORK_ERROR, TIMEOUT, CLI_OUTDATED。6) src/core/config-manager.ts：读写 ~/.agenzo-merchant-cli/config.json；默认 host https://agent.everonet.com；导出 getHost/setHost/resetHost。7) src/core/version.ts：import package.json 版本；compareVersion；读响应头 X-CLI-Min-Version，本地低于则抛 CLI_OUTDATED 并以退出码 2 退出（可参考 agenzo-token-cli）。8) src/core/api-client.ts：https 客户端，base=配置 host，ride 端点在 /api/v2 前缀；请求头 X-API-Key:<key>；写操作支持 Idempotency-Key 头（不放 body）；解封装 {success,data,error,request_id}——成功返回 data，失败按 error.code 抛 CliError、用 error.message 展示；读 X-CLI-Min-Version 做版本协商；网络/超时映射 NETWORK_ERROR/TIMEOUT。9) src/core/formatter.ts：table/keyValue/status 人类可读输出。10) src/core/output.ts：emit(data, format)，默认 json(JSON.stringify)、table 走 formatter；并提供 --help --format json 时输出该 verb 参数/响应 schema 的 helper。11) src/core/prompt-engine.ts：用 @inquirer/prompts 对缺省必填参数（api-key、idempotency-key 等）交互式索取，--yes 时跳过确认。12) src/types/api.ts：ride 全部请求/响应 TS 类型（Pickup/Dropoff{lat,lng,name}、QuoteRequest、VehicleClass{vehicle_class,price{amount,currency,quote_id},passenger_capacity,luggage_capacity}、BookRequest、订单状态字符串联合（大小写敏感：Pending/Accepted/On my way/Waiting/On board/At destination/Rejected/Cancelled/Customer no show/Driver no show）、CancelResponse{cancellation{cancellation_fee,reversal_amount,currency}}、ListOrdersResponse{orders,total,page,page_size}）及 services 注册表类型；金额为货币常规单位(decimal，非分)。13) src/utils/idempotency.ts：幂等键校验/规范化，缺省提示，--yes 模式缺失抛 PARAM_IDEMPOTENCY_KEY_REQUIRED。14) src/index.ts：commander 入口；全局 flag --format <json|table>(默认 json)、--yes、--api-key <key>；注册三组：config(set-host <url>/reset-host/show，此处用 config-manager 直接完整实现，纯本地)、ride(quote/book/get/cancel/list-orders)、services(list/get <service-id>)。为 ride 与 services 各 verb 创建骨架文件 src/ride/{quote,book,get,cancel,list-orders}.ts 与 src/services/{list,get}.ts，每个导出统一契约的 builder（如 export function buildQuoteCommand(): Command，返回已接好 flag 的子命令，action 暂抛 not-implemented，并预留 schema 对象供 --help --format json），index.ts import 并挂载。约束：命令文件之间不互相 import、不共享可变状态，只依赖 core/types/utils。务必保证 npm install + npm run build + npx tsc --noEmit + npx eslint src 全通过，dist/index.js 生成，--help 列出 config/services/ride。
